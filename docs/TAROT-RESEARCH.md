# 塔罗知识与产品研究（2026-10-09）

## 已核查的来源与采用方式

| 来源 | 发现 | 本地实现 |
|---|---|---|
| [Joan Bunning：Quick Insight](https://www.learntarot.com/quickinsight.htm) | 三个位置分别观察核心情况、影响因素和建议 | 增加「现状与建议」三牌阵；明确把位置传给解读模型 |
| [Joan Bunning：逆位](https://www.learntarot.com/less17.htm) | 逆位并非天然负面，可考虑表现受到限制等情形 | 根据实际正逆位选牌义；提示结合情境解释，不把逆位一律当坏事 |
| [Waite：《The Pictorial Key to the Tarot》](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot) | 韦特体系历史牌义的可追溯原始参考 | 在牌义手册提供阅读入口；不把历史占卜说法当成现代事实证据 |
| [Tarotoo 数据集](https://github.com/Tarotoo-com/tarotoo-tarot-dataset) | 覆盖78张牌及正逆位、感情、事业等字段；仓库提供MIT许可，并说明内容由AI生成后审校 | 评估为后续结构化扩展的候选；本次保留已覆盖78张的中文牌库，避免把额外AI文本直接当成权威知识 |
| [Labyrinthos：反思与评估牌阵](https://labyrinthos.co/blogs/learn-tarot-with-labyrinthos-academy/judgement-tarot-card-spread) | 以明确的位置问题引导反思，而非只列出牌名 | 首页显式提供六种牌阵，显示张数和位置，保留自动推荐；未复制该网站的具体牌阵 |

网页版权教学内容仅作为方法参考和链接，没有整篇复制。78张牌的中文含义沿用本项目原牌库，不能声称本次导入了新的外部知识库。

## 产品决定

1. 通用入口默认三牌「现状/影响因素/建议」，而非隐藏的单牌兜底。用户可选择单牌、时间三牌、情感四牌、选择五牌、生命七牌；自动推荐保留原关键词规则。
2. 每次解读明确提供牌阵名、逐张牌位、牌名、正逆位、对应牌义和关键词；回答先给建议，再解释依据。
3. 温暖的表达通过承接情绪、联系现实背景、给出行动获得。不会为了安慰而承诺结局，不推断第三方内心，不用生日捏造星盘。
4. 后续追问复用原牌组与最初解读，最近四轮承接上下文，逐轮限长。成功答案写回同一条本机历史；失败内容不保存成答案。
5. 生日、昵称、背景均可不填。输入的信息会发送给OpenAI，成功解读会保存到本机历史；不新增外部数据库。
6. 已有78张中文牌库足够小，按抽中牌直接提供知识即可。本次不增加向量数据库、训练流程或额外依赖。

## 使用示例

打开首页 → 填写问题 → 默认看到「本次抽 3 张：现状 → 影响因素 → 建议」→ 抽完三张 → 查看解读 → 在「继续聊聊这组牌」追问。

访问 `/cards` → 搜索「权杖六」→ 显示一张匹配牌 → 勾选「查看逆位」切换到对应中文牌义。无需API Key，也不会产生模型调用。

## 验证边界

界面行为用React组件测试、提示词与服务端请求用单元测试验证。只有提供有效OpenAI Key并完成真实调用后，才能评价生成语言的质量、稳定性和成本；单元测试不代表模型实际输出达标。
