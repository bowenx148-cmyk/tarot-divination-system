# 可视化牌阵选择规格

目标：按用户两张参考图建立黑金标题、浅金底色的可点击牌阵图鉴，编号与牌位含义明确对应，用户自主选择后驱动真实抽牌。

方案：沿用原有 radio 选择和 TarotSpread 数据；增加12个参考牌阵，保留6个现有牌阵。SVG绘制编号牌背，不引入依赖；桌面三列、平板两列、手机一列，保留自动推荐及默认三牌。所有牌阵在同一图鉴内可滚动浏览。

验收：18种牌阵均显示正确牌数、编号布局、牌位含义和适用场景；选择二牌、八牌及自动推荐正确传入 store；历史记录旧牌阵保持兼容；radio键盘操作可用，选中状态明显，摘要随选择更新。

测试：布局覆盖与坐标边界、DOM牌数与编号、手动八牌提交和自动推荐切换；全量 Vitest、类型检查、lint、HTTP首页验证。文档提供可运行交互示例。验证后归档并更新 SPEC。


用户补充：主页仅罗列简洁图卡。点选后进入独立牌阵说明视图，展示所有牌位和抽牌方法；支持返回列表和确认使用。详情页与图鉴切换时移动焦点，避免键盘焦点丢失。


验收完成：325项原有测试和21项新增测试通过，类型检查与lint通过；HTTP200验证首页简洁入口。浏览器人工视觉验收与真实模型调用未执行。
