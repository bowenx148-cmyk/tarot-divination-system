# 下次开机后怎么打开

本机是网站服务器。关机后公网链接会暂时失效，保存的知识库、密钥、用户名和历史不会因此清空。

1. 开机并联网，进入 `D:\talo\indigo-tarot-runtime`。
2. 双击根目录的 `启动公网分享.cmd`，等待打印 `Share this URL`。本次已构建最新版，不需每次重建。
3. 本机使用页面：`http://127.0.0.1:3001/`；开发者后台：`http://127.0.0.1:3001/developer`。原开发者凭据仍有效，后台仅本机开放。
4. 对外发送启动窗口打印的公网地址。对方可正常使用抽牌和AI功能；试用限制保持。不要把后台密钥发给用户。

若端口占用，先双击 `停止公网分享.cmd` 再启动。该脚本只停止本项目记录的分享进程，不结束其他程序。

如需编辑代码并使用原来的3000开发地址，在项目PowerShell执行：

```powershell
npm.cmd run dev -- --hostname 127.0.0.1 --port 3000
```

已有运行中的3000服务时不重复启动。修改后需按部署说明重新构建公网版；不能把热更新的本地开发页当成公网已更新。

本次报告见 [调研与产品报告](TAROT-PRODUCT-RESEARCH-2026-10-10.md)，真实回答见 [模型样本](REAL-MODEL-SAMPLES-2026-10-10.md)。关机采用正常系统关机，不使用强制关闭参数；其他程序若有未保存内容，系统可能要求处理后才完成关机。
