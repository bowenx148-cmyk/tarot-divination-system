# 分类知识库与用户材料

## 内容与来源

- `lib/knowledge/tarotoo-cards.json`：78张韦特牌的结构化参考，来自 [Tarotoo](https://github.com/Tarotoo-com/tarotoo-tarot-dataset)。核查 [MIT许可证](https://github.com/Tarotoo-com/tarotoo-tarot-dataset/blob/main/LICENSE)，完整许可证保留在同目录。原作者注明AI辅助生成并审校，不能等同实证知识。
- `lib/knowledge/domain-notes.ts`：78张牌 × 感情/事业/学业/收入 × 正逆位，共624条中文情境参考。本地逐牌编辑；感情/事业同时检索Tarotoo对应英文条目，学业/收入是根据象征与现实行动整理的本地应用，不冒称外部书籍原文。
- `lib/tarot-reference.ts`：参考用户提供材料整理的反思原则。原图仅保留在本机私有 `docs/knowledge/user-materials/`，不随发布副本分发；未取得原图公开转载许可。公开摘要不采用命运、能量或准确性承诺。各素材许可与缺口见 [来源清单](../../THIRD_PARTY_NOTICES.md)。
- `lib/tarot-knowledge.ts`：按牌ID、正逆位和问题领域检索，只发送抽中牌所需的条目；复合问题可检索多个领域，追问另检索新领域。

公开网页内容有时会变化。本次通过网页读取取得结构化快照并检查78张覆盖，直接GitHub下载受到DNS解析故障影响；没有声称固定在某个Git提交。JSON文件SHA256见 `lib/knowledge/source.json`。

## 截图采用与不采用的内容

采用：问题明确、时间范围清楚；尽量一次讨论一个问题；现实行动能改变处境；不承诺百分百准确；保护本人和第三方隐私；情绪强烈时先提供支持；反复抽牌前先沿用原牌追问。

保留在原资料中，但不转成系统要求：必须收费或物品交换；不信不占、怀疑者不配使用；牌会戏耍或惩罚用户；能量污染；某时间跨度更准确。系统不会因为怀孕、怀疑塔罗或不愿付费而拒绝普通反思对话。

不提供生死、寿命、疾病/怀孕诊断、彩票数字、股票方向、法律结果或无关第三方隐私的牌面预测。收入领域支持预算、技能、交付与现金流反思，不提供保证收益的投资判断。

## 教学调研

- [LearnTarot逆位课](https://www.learntarot.com/less17.htm)：逆位不是天然负面，须结合表现和情境理解。只概括方法，不复制整课。
- [LearnTarot三牌指引](https://www.learntarot.com/quickinsight.htm)：牌位提供不同观察角度，组合解读不能只罗列牌名。
- [抖音检索样本](https://www.douyin.com/shipin/7334301198037583922)：索引中有圣杯十等牌在感情场景的说法，但属于大众占卜，未取得完整可核查的教学视频转录；没有复制文稿或把对第三方内心的断言入库。抖音来源不具备完备的78张逐牌覆盖。

## 可运行示例

牌义手册 `/cards` → 搜索「权杖六」→ 选择「学业」→ 勾选「查看逆位」。预期显示学习领域参考「排名压力或发挥失常，找具体失分点。」；切换「收入」后显示「表面认可不等于进账，核实奖励条件。」。

这些是条件性的反思提示，并不证明用户发生了上述事情。模型需把它们联系实际问题、背景和牌位，而非原样拼接成事实。
